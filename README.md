## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/your-username/DSA-in-C-Lab.git
```

Move to the required experiment folder:

```bash
cd Experiment-01-Array
```

Compile:

```bash
gcc array_operations.c -o array
```

Run:

```bash
./array
```
